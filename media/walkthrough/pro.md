# Pro reports

* **Show Host Breakdown**: Per host: requests, transferred bytes, time, average wait and errors, to see which server or third party costs the most.
* **Show Caching And Compression**: Text responses sent without compression, responses without caching headers, and how much compression saved.

The first Pro command starts a free 14-day trial on this computer. After the trial, Pro is a one-time purchase: USD 19 (Personal) or USD 39 per user (Business).
